### Events at NJIT
I realized that the method by which students can learn about events at NJIT is rather Archean. So, I'm currently working on an iOS app that I hope solves for this! The app will be paired with a Twitter Bot and a Public API for events. Source code is available on GitHub: [iOS](https://github.com/jayrav13/njit-events-app) | [API](https://github.com/jayrav13/njit-events-api). Follow us [@EventsAtNJIT](https://twitter.com/EventsAtNJIT) on Twitter. Questions / Comments / Concerns? Email us at [njit.events.app@gmail.com](mailto:njit.events.app@gmail.com).

Code is publicly available via [GitHub](https://github.com/jayrav13/flask-sdn).

#### Hackathons

#### Spring 2016

### PennApps
We built [Storyteller](http://devpost.com/software/storyteller-y3sh9v). Teamed up with [Sakib Jalal](https://github.com/sakib), [Alec Huang](https://github.com/alectrolytes) and Ema Tasmin to create this location-based social app which is a spin on [Humans of New York](http://www.humansofnewyork.com/). As you make your way through your city throughout the day, you miss so many chances to connect with the incredible people around you. If they're not featured on HoNY for being ordinary people leading extraordinary lives, we'll never hear their story. Our app connects you with those you pass by every day, giving you a chance to learn about who you've passed by throughout the day. Be inspired - it may encourage you to stop and say hey more often! Worked on the iOS App with Alec and Ema. Source code is available on [GitHub](https://github.com/jayrav13/homl).

### Dragon Hacks
We built [Pay Park](http://devpost.com/software/pay-park) - winners of the Best Use of Amazon Web Services hack! Teamed up with [Sakib Jalal](https://github.com/sakib), [Alec Huang](https://github.com/alectrolytes) and [Varun Shah](https://github.com/thevarunshah) to build this iOS App that has two components: an API for city governments to populate our database with street parking availability throughout their city in a standardized way, and a client-facing API that allows users to find, select and pay for street parking all from an app. Gone are the days of parking meters and kiosks. Worked on the iOS App with Alec. Source code is available on [GitHub](https://github.com/jayrav13/park-pay).

#### Fall 2015

### YHack
We built [fnActivists](http://devpost.com/software/fnactivists). Teamed up with [Jeet Patel](https://www.linkedin.com/in/jeetpatel1022) to build this iOS App based on the [Fiscal Note](https://www.fiscalnote.com/), which delivered an exhausting amount of government and legislative data. Wrote the Python Flask server that interacted with the API, managed user data in MySQL and served a controlled amount of data to the iOS Client. The app displayed data to users in a visual way, allowed users to set reminders for tags that related to their political interests, and more. Source code is available on [GitHub](https://github.com/jayrav13/fnactivists-backend).

### BostonHacks
We built [Tonifai](http://devpost.com/software/tonifai). Teamed up with [Varun Shah](https://github.com/thevarunshah) and [Ananth Rao](https://github.com/ananthamapod) to build this Twilio-based app that "converted" your friends' Contacts image on your phone into a tune, called them and "sang" it to them. Wrote the [iOS App](https://github.com/jayrav13/tonifai) that sent a request to a server, along with the friend's contact information and image, to place a phone call through Twilio.

### HackUMass
I built [Google Notepad](https://github.com/jayrav13/google-search-notepad), a Google Chrome extension that gives you a `textarea` when you search "notepad" in Google Search. After typing in your quick note, pressing enter sends the email to the account you're logged in with using Mandrill. Source code is available on [GitHub](https://github.com/jayrav13/google-search-notepad).

We built [Bump It Up](http://devpost.com/software/the-bumper-program). Teamed up with [Dylan Lesko](https://github.com/dylanlesko) and [Ashton Welles](https://github.com/ashton007) to build this iOS app that detected road conditions using the built in accelerometer. This data was sent to a server side Flask app that identified major variaances in the data as potential potholes or bad road conditions. Constructed a public-facing API that other developers can use to consume our user-generated data. Source code is available on [GitHub](https://github.com/jayrav13/bump-it-up-hackumass).

### Post-Exams Stress Hack!
I built "Guess That Number!", a post-exam stress hack. This Twilio-based app replicates the "What number am I thinking of?" game! Guess a number and text it to +1 (908) 360-5009! A Flask app manages contests and contestants in a SQLite database. Every time someone wins, a new contest is launched. Give it a try! Source code is available on [GitHub](https://github.com/jayrav13/twilio-number-contest).

### hackNY
We built [Rubik's Hacks](http://devpost.com/software/ru6-x-h-x). Teamed up with [Ismail Mustafa](https://github.com/ismailmustafa) to build a Rubik's Cube solver.
